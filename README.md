# Kalkulator Aritmatika Dasar

## Deskripsi
Kalkulator yang langsung mengeluarkan 5 hasil operasi sekaligus yaitu:

1. Penjumlahan (+)
2. Pengurangan (-)
3. Perkalian (×)
4. Pembagian (÷)
5. Modulo (%)


## Persyaratan
* C Compiler (Seperti GCC/Clang)

## Cara Menggunakan

1. Unduh atau clone repositori ini:
   https://github.com/FauzanSammyMochtar/Kalkulator-Aritmatika-Dasar.git

2. Masuk ke folder proyek:
   
   cd Kalkulator-Aritmatika-Dasar

3. Compile program:

clang kalkulator_aritmatika_dasar.c -o kalkulator_aritmatika_dasar

5. Jalankan program:
   ./kalkulator_aritmatika_dasar
